Path tracer: traversal parity probe

Builds the traversal kernel on this browser's WebGPU implementation, drives a corpus of rays through it, drives the same corpus through the CPU traversal in the same wasm instance, and compares. The desktop runs the exhaustive version of this check; what only a browser can answer is whether its own WGSL front end accepts the kernel at all.

Path tracer: material response probe

Builds both BSDF probe pipelines and the path kernel, which is the deepest composition in the shader directory, checks separately that the path kernel builds on a device at core WebGPU limits, then draws a small batch and reports the directional albedo at four roughnesses. Two things are being asked. Whether this browser's WGSL front end accepts the lobes at all, which is the half only a browser can answer and the reason the uniformity discipline exists. And whether a browser that compiles them computes the same thing: an albedo above one would mean the surface returns more light than reached it.
