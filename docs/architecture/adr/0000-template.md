# NNNN. Short present-tense statement of the decision

- **Status**: proposed | accepted | superseded by NNNN (link to it)
- **Date**: YYYY-MM-DD
- **Embodied in**: the release the decision first shipped in, for a retroactive ADR. Omit for
  a decision not yet implemented.

## Context

What forced a decision. The constraint, the conflict, or the question that could not be left
open. State it so a reader who was not there understands why doing nothing was not an option.

Cite the code that makes the situation concrete. An ADR whose context is abstract cannot be
checked against reality later.

## Options considered

Each option gets a name and an honest account, including the ones not chosen. An ADR that
lists one option is a decision nobody argued with, which usually means nobody understood the
cost yet.

### Option A: name

What it is, and what it would cost.

### Option B: name

Same.

## Decision

The choice, stated in one or two sentences, in the present tense, as a rule.

## Consequences

What this makes easy, what it makes hard, and what it forecloses. Be specific about the
second and third of those, because the first is the part everyone already believes.

State the enforcement: what mechanically prevents this decision from being violated by
accident. If the answer is nothing, say nothing, and it becomes a candidate for
[09-evolution-and-roadmap.md](../09-evolution-and-roadmap.md).

## Notes

Anything a future reader needs that does not fit above: a measurement, a link to the code
that implements it, a thing that was tried and abandoned.
